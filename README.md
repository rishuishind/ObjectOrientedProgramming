# Java OOPS Learning Project

This workspace contains a very basic Java project structure for learning object-oriented programming.

## Structure

- `src/main/java` - place your Java source files here
- `src/main/resources` - optional configuration or resource files
- `src/test/java` - place test classes here when you start writing tests
- `src/test/resources` - optional test resources

## Getting Started

1. Create a package folder inside `src/main/java`, for example `com/example`.
2. Add a Java class file, such as `Main.java`.
3. Compile and run using your IDE or command line.

## Notes

- This setup is intentionally minimal so you can focus on learning Java OOP.
- No build tool files are included yet.
